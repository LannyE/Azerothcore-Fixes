This repository is for my custom fixes outside of the normal Azerothcore Repo.
These are mostly Blizzlike events, RP, encounters, waypoints, etc. missing from Azerothcore.
If what I was fixing is available in the other emulators I do pull and adapt the information to be put into Azerothcore. 

If someone wants to implement any of this in Azerothcore please feel free.
All I ask is you keep the IDs (Creature, Spawn Groups, etc.) the same, if possible.
